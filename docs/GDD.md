# 《废土猎人》GDD（垂直切片版）

> 类型：末日废土 · 战车改装 · 回合制 RPG
> 引擎：Godot 4.x（GDScript）
> 本文档范围：只覆盖垂直切片（可玩最小闭环），不是完整版设计。

---

## 1. 一句话与玩家幻想

开着一辆自己拼出来的破车，在荒原上找赏金首挣钱，把车越改越狠。

**差异化落点**：改装不是「升级菜单」，而是一道载重/出力/槽位的取舍题——想装大炮就得换引擎，换了引擎车变重、机动下降、出手变慢。

**原创性声明**：世界观、名词、美术、剧情全部原创，不使用任何既有系列的素材、名称或设定。

---

## 2. 核心循环

```
探索地图 → 遭遇战斗 → 战利品与赏金 → 回城修理/补给/改装 → 探索更远的区域
```

每一环的产物必须是下一环的燃料：

| 环节 | 产出 | 消耗 |
|---|---|---|
| 探索 | 赏金首情报、藏车点 | 时间、燃油（切片暂不做燃油） |
| 战斗 | 金钱、素材、装备 | 弹药、装甲 |
| 回城 | 更强战车 | 金钱 |
| 改装 | 更高机动/火力 | 载重余量 |

**设计红线**：任何一次改装都必须让玩家感觉到「我变强了，但我失去了什么」（载重、机动、槽位）。

## 3. 战斗系统

### 3.1 流程

1. 进入战斗 → 计算所有单位机动值 → 降序排列行动顺序（同值随机）
2. 每个单位行动：选择目标 → 选择武器/攻击 → 结算命中 → 结算伤害
3. 一方全灭或玩家人物 HP = 0 → 战斗结束
4. 战后结算：经验、金钱、掉落；扣弹药不做（弹药在战斗中即扣）

### 3.2 公式

```
命中率 HIT = clamp(武器命中 + C装置命中修正 - 目标回避, 30, 99)
基础伤害   = 攻击力 - 目标防御 × 0.5
伤害       = max(1, round(基础伤害 × rand(0.9, 1.1)))
暴击       5% 概率，伤害 ×1.5
```

### 3.3 装甲与生命（关键规则）

- **装甲（armor）是吸收池**：有装甲时先扣装甲，溢出部分才扣 HP。装甲为 0 后全部伤害打 HP。
- **战车**：底盘提供装甲值。装甲归零后伤害直接打乘员 HP，HP 归零 → 战车报废，战斗失败。
- **破甲不等于失去行动力**：装甲归零的单位仍会继续行动。否则敌人一破甲就变靶子，节奏会崩（M0 模拟验证过这条）。
- **人物**：只有 HP，没有装甲池。
- 因此有效血量 = `armor + hp`，这是判断一场战斗节奏的唯一口径。

### 3.4 弹药

- 每件武器有独立弹数，每次射击消耗 1 发，打完不能再用（不是自动补满）。
- 弹药**不计重量**，只花钱：主炮 30G/发、副炮 2G/发、SE 60G/发（战后补给）。
- 弹药是本作唯一的「持续成本」，用来控制玩家无脑刷怪。

### 3.5 胜利与失败

- 胜利：敌方全灭。
- 失败：人物 HP = 0（战车的 HP 即乘员 HP，归零即报废）。
- 失败惩罚：被拖回最近城镇，损失 20% 现金，战车按缺损装甲付修理费。

### 3.6 机动值（出手顺序）

```
机动 = clamp(round(引擎出力 / 战车总重 × 20), 5, 40)
```

人物固定机动 18。这是「改装影响手感」的直接体现：超载的车会最后一个动。

## 4. 战车系统

### 4.1 部件

| 部件 | 决定 | 数量 |
|---|---|---|
| 底盘 | 装甲、槽位（类型+尺寸）、地形适应 | 1 |
| 引擎 | 出力（载重上限）、机动 | 1 |
| C 装置 | 命中、回避 | 1 |
| 主炮 | 单发高伤、弹数少 | 按槽位 |
| 副炮 | 低伤高频、弹数多 | 按槽位 |
| SE | 特殊弹（范围/高伤） | 按槽位 |

### 4.2 改装校验（必须全部通过才能出车）

1. 槽位数量：`已装武器数 ≤ 底盘对应槽位数`
2. 槽位尺寸：武器 size（S/M/L）≤ 槽位 size
3. 载重：`sum(全车部件重量) ≤ 引擎出力`

示例（切片内的三套标定配置，用于验证数值）：

| 配置 | 部件 | 总重 | 出力 | 机动 | 结论 |
|---|---|---|---|---|---|
| 初始吉普 | 吉普380 + 小型引擎180 + C装置60 + 75mm 150 + 机枪45 | 815 | 900 | 22 | 可出车 |
| 装甲卡车 | 卡车720 + 中型引擎320 + C装置60 + 105mm 260 + 火神80 + 导弹120 | 1560 | 1500 | — | **超载，必须换引擎或卸 SE** |
| 重装坦克 | 坦克1100 + 重型引擎520 + C装置90 + 电磁炮420 + 加特林140 | 2270 | 2400 | 21 | 可出车，但装不下 SE |

第三行是设计意图：最强主炮与 SE 不能共存，玩家必须选。

### 4.3 损坏与修理

- 装甲不自动恢复。回城修理按 `缺失装甲 × 3G` 计价。
- 战车损坏后仍可拖回，但本次战斗不能再上场。

## 5. 经济

| 项 | 数值 |
|---|---|
| 初始现金 | 500G |
| 普通怪掉落 | 25–200G |
| 赏金首 | 1500G |
| 修满一辆吉普装甲 | 360G |
| 修满一辆坦克装甲 | 1020G |
| 一把 105mm 主炮 | 2200G |

设计目标：第一个大目标是攒钱买 105mm 主炮或中型引擎（二选一）。赏金首「赤蝎」是这道门槛的验收——用初始吉普挑战大概率会失败（有效血量 160，约 5 轮被打穿，1000 场实测胜率 20.2%），这是刻意的难度墙，不是数值 bug。换成装甲卡车 + 105mm 后才有稳定胜率（实测 81.6%）。

## 6. 世界与地图（切片范围）

- 1 座城镇：酒吧（接赏金）、修理厂、武器店、存档点
- 2 片野外：公路带（低危）、沙漠带（中危）
- 1 个小迷宫：废弃军事基地（终点是赏金首）
- 地形与载具：吉普/卡车可走公路+沙地；坦克额外可走山地。地形不满足则不可进入（用视觉与提示明示，不做隐藏）

---

## 7. 任务结构

- 主线（切片内只有一段）：接取「赤蝎」赏金 → 找到基地 → 击杀 → 回城领赏
- 支线模板 2 个：讨伐 N 只沙蝎；把修理箱送到野外 NPC
- 隐藏内容 1 个：基地角落可挖出一台旧引擎（唯一一次「白嫖变强」的爽点）

---

## 8. 垂直切片验收标准

切片完成 = 下面全部成立：

- [ ] 从城镇出发，能在 15 分钟内走完「改装 → 出战 → 掉落 → 回城换装」一整圈
- [ ] 至少 2 辆可改装战车，17 种部件（3 底盘 + 4 引擎 + 2 C 装置 + 8 武器），能真实触发「载重不够装不上」
- [ ] 4 种普通敌人 + 1 个赏金首，数值符合第 3 章公式
- [ ] 战斗有行动顺序、命中、暴击、弹药、装甲吸收、失败惩罚
- [ ] 存档能保存：现金、战车配置、已击杀赏金首、人物状态

## 9. 技术方案（Godot 4）

### 9.1 目录结构

```
metalmax_like/
├─ data/                  # 全部配置表（JSON，运行时读取）
├─ docs/                  # 设计文档
├─ scenes/
│   ├─ world/             # 地图、城镇
│   ├─ battle/            # 战斗场景
│   └─ ui/                # 改装界面、菜单、对话框
├─ scripts/
│   ├─ autoload/game_data.gd   # 加载并索引所有 JSON 表
│   ├─ autoload/game_state.gd  # 玩家状态、存档
│   ├─ battle/                 # 战斗结算、单位、AI
│   └─ garage/                 # 改装校验
└─ project.godot
```

### 9.2 数据驱动约定

- 所有数值只出现在 `data/*.json`，代码里不写死任何攻击力、价格。
- 用 id 建立索引：`GameData.weapons["w_cannon75"]`。
- 战斗公式集中在 `scripts/battle/battle_math.gd` 一个文件里，方便调参。

### 9.3 场景拆分（切片）

| 场景 | 职责 |
|---|---|
| `GarageScene` | 改装界面：选底盘/引擎/C装置/武器，实时显示总重、出力、机动、剩余槽位 |
| `BattleScene` | 回合制战斗，行动条、目标选择、伤害飘字 |
| `WorldScene` | 2D 俯视地图移动、遭遇触发、城镇入口 |
| `TownScene` | 酒吧/修理/商店/存档 |

## 11. 风险与对策

| 风险 | 表现 | 对策 |
|---|---|---|
| 数值崩坏 | 后期一门炮秒全场 / 打不动 | M0 就写自动对战脚本，每次改表都跑 |
| 改装界面复杂 | 玩家看不懂为什么装不上 | 实时显示「剩余载重」与超标部件高亮 |
| 引导缺失 | 不知道去哪 | 酒吧给明确目标 + 地图标记，不做纯开放 |
| 内容量被低估 | 系统做完发现没东西可玩 | 先定「一张区域 = 多少分钟」，按分钟反推内容量 |
